#🚗 **CAN-Based Automotive Dashboard | Embedded Systems Project**

I'm excited to share my project, **CAN-Based Automotive Dashboard**, developed using Embedded C and the PIC18F4580 microcontroller.

🔹 **Project Overview:**
This project demonstrates communication between multiple Electronic Control Units (ECUs) using the Controller Area Network (CAN) protocol to monitor essential vehicle parameters.

⚙️ **Key Features:**
✅ Real-time vehicle speed monitoring
✅ Engine RPM monitoring
✅ Gear position selection
✅ Left, right, and hazard indicator control
✅ CAN-based communication between multiple ECUs
✅ LCD-based display and digital keypad integration

🛠️ **Technologies & Tools:**
• Embedded C
• PIC18F4580 Microcontroller
• CAN Protocol
• ADC (Analog-to-Digital Converter)
• LCD and Digital Keypad
• MPLAB X IDE and XC8 Compiler

🎯 **Learning Outcomes:**
This project helped me strengthen my understanding of embedded programming, microcontroller peripherals, CAN communication, and automotive embedded systems.

I'm looking forward to applying these skills to real-world embedded software and automotive firmware development.
